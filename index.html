01  /  Why Solana for $THELIST

Meme velocity is a strategic asset

05  /  Step-by-Step Launch Guide

From zero to live on Solana mainnet

This is the complete, practical sequence. Follow it in order. Estimated total time: 3–6 hours for the token launch itself. The staking program is a separate build (see Phase 2).

Phase 1 — Wallet & Funding Setup

1

Install Phantom Wallet

Go to phantom.app and install the browser extension (Chrome/Brave recommended). Create a new wallet. Write down your seed phrase on paper — never digitally. This wallet will be your launch wallet.

Cost: Free
2

Create a separate deployment wallet

Create a second fresh Phantom wallet. This will be your token deployer wallet. Keep it separate from your personal holdings. You'll revoke its authorities at launch anyway, but separation is good hygiene.

Cost: Free
3

Fund the deployment wallet with SOL

Send approximately 0.05–0.1 SOL to your deployer wallet. This covers token creation fees, metadata upload, and initial transactions. Buy SOL on Coinbase, Kraken, or Binance and withdraw directly to your Phantom wallet address.

Cost: ~$5–$15 USD in SOL

Phase 2 — Token Creation

Option A: Pump.fun (recommended — fastest, most reach)

Pump.fun is the dominant Solana memecoin launchpad. A token launched here gets immediate exposure to millions of active traders. It handles bonding curve liquidity, token creation, and Raydium graduation automatically.

1

Prepare your token assets

You need: (1) Token logo — square image, minimum 500×500px, PNG format. Design something with the $THELIST branding — the document/list motif, the gold-and-dark colour scheme. (2) Token description — 200 characters max on Pump.fun. Make it punchy and reference the mission. (3) Social links — your X handle, Telegram group link, and website URL ready to paste.

Cost: Free (design time only)
2

Go to pump.fun and connect wallet

Navigate to pump.fun. Click "Start a new coin" in the top right. Connect your deployer Phantom wallet. You'll be prompted to approve a small SOL transaction to create the token account.

Cost: ~0.02 SOL
3

Fill in token details

Name: "The List Coin" — Ticker: "THELIST" — Upload your logo — Paste your description referencing the Epstein documents and awareness mission — Add your X, Telegram, and website links. Double-check everything. Once deployed, the ticker cannot be changed.

Cost: Free (part of creation tx)
4

Set your developer buy (optional but recommended)

Pump.fun lets you optionally buy a small amount of your own token at launch to seed initial price action. Setting a small buy (0.01–0.05 SOL) is common and shows conviction. Do not buy a large amount — it looks like a pump-and-dump setup and the community will notice.

Cost: Your optional buy amount
5

Deploy and confirm

Click "Create coin." Approve the transaction in Phantom. Your token is now live on Solana mainnet. Pump.fun will give you a page URL immediately — this is your token's home base until it graduates to Raydium. Save the token mint address (the public key).

Cost: ~0.02 SOL total

Option B: Manual deployment via Solana CLI (more control)

For direct control over supply, metadata, and authority revocation, deploy via the Solana CLI. This requires Node.js installed on your machine.

# Install Solana CLI tools
sh -c "$(curl -sSfL https://release.solana.com/v1.18.0/install)"
# Set to mainnet
solana config set --url https://api.mainnet-beta.solana.com

# Install SPL Token CLI
cargo install spl-token-cli

# Create token with 6 decimals
spl-token create-token --decimals 6
# → Save the TOKEN_MINT_ADDRESS output

# Create token account
spl-token create-account TOKEN_MINT_ADDRESS

# Mint 1,000,000,000 tokens to your account
spl-token mint TOKEN_MINT_ADDRESS 1000000000

# CRITICAL: Revoke mint authority (makes supply fixed forever)
spl-token authorize TOKEN_MINT_ADDRESS mint --disable

# CRITICAL: Revoke freeze authority
spl-token authorize TOKEN_MINT_ADDRESS freeze --disable

# Verify both are revoked
spl-token display TOKEN_MINT_ADDRESS

Critical: Do NOT skip the authority revocation steps. A token with active mint or freeze authority will be flagged as a rug risk by every scanner (RugCheck, BirdEye, DEXScreener) and the community will not trust it.

Phase 3 — Metadata & Verification

1

Upload logo to IPFS via Pinata

Go to pinata.cloud — create a free account — upload your token logo PNG. Copy the IPFS hash (format: ipfs://Qm...). This is your permanent, censorship-resistant logo URI. Never use a centralised image host for token metadata.

Cost: Free (Pinata free tier)
2

Create and upload metadata JSON

Create a metadata.json file with your token name, symbol, description, image URI, and social links. Upload this JSON to IPFS via Pinata as well. This follows the Metaplex metadata standard.

Cost: Free
3

Attach metadata on-chain via Metaplex

Use metaplex.com's token metadata tool or the Metaboss CLI to attach your IPFS metadata URI to your token mint address. This is what makes your logo and name appear in wallets and on DEXScreener/BirdEye.

Cost: ~0.01 SOL
4

Verify on RugCheck and BirdEye

Go to rugcheck.xyz and enter your mint address. Confirm the report shows: Mint authority disabled ✓ — Freeze authority disabled ✓ — No insider wallets holding large %. Share your RugCheck report in your community immediately — it builds trust.

Cost: Free

Phase 4 — Liquidity & Trading

1

Pump.fun graduation (if launched there)

Pump.fun tokens automatically graduate to Raydium when they reach a $69,000 market cap on the bonding curve. At this point, Pump.fun burns the LP tokens and migrates liquidity to Raydium's AMM. This happens automatically — your token is now a full Raydium pair with locked liquidity.

Cost: Automatic
2

Manual Raydium pool (if deployed via CLI)

Go to raydium.io → Liquidity → Create Pool. Select your token and SOL as the pair. Set your initial price by choosing the ratio of tokens to SOL you deposit. After creating the pool, burn the LP tokens by sending them to a dead address (So11111...11112). Never hold LP tokens as a developer — it signals rug risk.

Cost: ~0.5–2 SOL for seed liquidity (minimum)
3

Submit to DEXScreener and BirdEye

Once your Raydium pool is live, your token will automatically appear on DEXScreener and BirdEye within minutes — no submission needed. Update the token info on DEXScreener (dexscreener.com/solana/YOUR_PAIR_ADDRESS) to add your logo, description, and social links. There is a small SOL fee to update info on DEXScreener.

Cost: ~0.1 SOL (DEXScreener update fee)

Phase 5 — Staking Program Deployment

The Awareness Multiplier staking program requires Solana smart contract (program) development using the Anchor framework. This is the most technically complex part. Your options:

Hire an Anchor developer

Timeline: 2–4 weeks

Find experienced Solana/Anchor developers on the Solana Discord (#developers channel), Superteam.fun talent network, or Upwork. Budget $3,000–$10,000 for a full staking + Awareness Points contract.

Use a staking template

Timeline: 1–2 weeks

Several open-source Anchor staking templates exist on GitHub. Search "anchor staking program solana". A developer can adapt an existing template faster than building from scratch — reduces cost to $1,500–$4,000.

Streamflow or similar

Timeline: Days

Streamflow.finance provides no-code staking and vesting contract creation for SPL tokens. Less customisable (no Awareness Multiplier built in) but gets basic staking live immediately while custom contract is built.

Launch without staking first

Timeline: Now

Launch the token, build the community, use the first weeks to build hype and raise awareness. Deploy staking in Phase 2 once you have a community funding it. Many successful projects do this.

Phase 6 — Community Infrastructure

1

X (Twitter) account

Create @TheListCoin (or similar). Post the RugCheck report, mint address, Pump.fun link, and token mission in the first 3 tweets. Pin a tweet with all links. Start following and engaging with Solana CT (Crypto Twitter) — the algorithm rewards engagement, not followers.

2

Telegram group

Create a public Telegram group. Add a bot for real-time price/chart updates — @DexScreenerBot works well. Pin the rules and the RugCheck report. Telegram is where the core community lives for Solana memecoins.

3

Website deployment

Host your whitepaper HTML on Vercel (vercel.com) — free tier, connects to a GitHub repo, deploys in 2 minutes. Register a domain (thelistcoin.xyz or similar — .xyz is cheap at ~$1/year on Namecheap). Point DNS to Vercel.

Cost: ~$1–$15/year for domain
4

Submit to Solana token lists

Submit your token to the Solana token list on GitHub (github.com/solana-labs/token-list) and Jupiter's strict list (via their verification portal). Jupiter listing is crucial — it's the main DEX aggregator on Solana and unlocks massive trading volume.

Cost: Free (PR submission)
